# Digital Clock ⏰

A simple and responsive Digital Clock built using **HTML, CSS, and JavaScript**. It displays the current time in real time with a clean and user-friendly interface.

## ✨ Features
- Displays the current time in real time.
- Automatically updates every second.
- Clean and simple user interface.
- Responsive design for different screen sizes.
- change theme dark / light.

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript

## Live demo [ https://code-with-alia.github.io/digital_clock/] 

## 🎯 Purpose
This project was created to practice JavaScript fundamentals, time and date functions, and DOM manipulation while improving frontend development skills.
